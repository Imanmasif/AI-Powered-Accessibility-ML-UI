# AI-Powered Accessibility: Evaluating the Role of Machine Learning in Inclusive User Interface Design

[![DOI](https://img.shields.io/badge/DOI-10.1007%2F978--3--032--31048--4__6-blue)](https://doi.org/10.1007/978-3-032-31048-4_6)

## 📖 Abstract

The most recent studies in artificial intelligence (AI) and machine learning (ML) have enhanced digital access through systematic reviews, contrast recommendations, and real-time device detection systems. Nonetheless, the existing solutions are mostly static, fragmented, or diagnostic, with little to no integration of perceptual models and minimal or no empirical assessment from the visually impaired users. Available contrast checkers and WCAG-based tools have an assessment component, but no adaptive or customized remedial solution, and ML-driven colour and contrast models tend to be used out of accessibility contexts. Throughout these works, there is a distinct disconnect, which is the lack of real-time, ML-powered systems that can automatically identify and rectify the colour contrast barriers in active user interfaces. This paper is a response to this gap by introducing an adaptive, WCAG-compliant contrast optimization tool that applies supervised ML to make dynamic interface adjustments and is tested using mixed-method evaluation with visually impaired individuals. The strategy targets improving inclusive UI design with a transition of accessibility support moving towards real-time proactive adaptation instead of the traditional static checking. This work aims at designing and testing an ML-based, real-time system that automatically personalizes and corrects colour contrast in web interfaces to enhance readability by users with visual impairments. The evaluation shows improved task performance, reduced error rates, and increased perceived readability under adaptive contrast conditions.
